# FlappyBird Clone (SFML Version)
This is a SFML version of FlappyBird.

It's the port from the SDL version (you can find in main branch)

All code & assets (sprite and sound) are made by me.

Font by chequered

## Build instructions.
This project use SFML.

To build the project you just need to type `make run`
